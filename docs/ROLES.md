# Larship Safety – Roller og tilgang

## Kaptein
Full administrativ tilgang til fartøyets Larship Safety-system.

## Overstyrmann / Sikkerhetsoffiser
Samme administrative tilgang som Kaptein og ansvar for sikkerhetsoppfølging.

## Ansatt / Mannskap
Personlig konto med tilgang til egne oppgaver, tester, kontroller og relevante prosedyrer.

### Ansatte skal ikke kunne
- endre regelverk
- endre sikkerhetskrav
- administrere andre brukere
- endre systemets grunnoppsett
- slette data de ikke har rettighet til å slette

Tilgang skal håndheves teknisk med rollebasert tilgangskontroll, ikke bare skjules i brukergrensesnittet.
